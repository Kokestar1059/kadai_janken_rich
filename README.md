# ①課題名
じゃんけんアプリ（リッチ版）

## ②課題内容（どんな作品か）
- PCのWebカメラに手をかざすだけでじゃんけんができるアプリ
- 勝てないじゃんけん
- 「じゃん・け〜ん・ぽんっ！」のカウントダウン後にカメラがジェスチャーを認識して勝負する
- PCは勝つたびに嫌味なコメントがランダムで表示される

## ③アプリのデプロイURL
https://

## ④アプリのログイン用IDまたはPassword（ある場合）
- ログイン機能なし（そのまま使用可能）

## ⑤工夫した点・こだわった点
- **MediaPipe Gesture Recognizer** を使ったリアルタイムのジェスチャー認識
- 認識ループ（プレビュー用）とスナップショット認識（判定用）を分離し、「ぽんっ！」の瞬間だけを正確にキャプチャする設計にした


## ⑥難しかった点・次回トライしたいこと（又は機能）
- MediaPipe の `recognizeForVideo` はタイムスタンプが単調増加でないとエラーになる仕様で、ループとスナップショットで同じインスタンスを共有しながら競合しないよう管理するのが難しかった
- 次回は勝敗の統計（何戦何敗）をLocalStorageに記録して表示する機能を追加したい
- 「本当に勝てる手を出す」ではなく「後出ししてくる挙動」を入れると面白くなりそう
